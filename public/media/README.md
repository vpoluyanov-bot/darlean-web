# Homepage media

Everything here is generated by `scripts/encode-media.mjs` from the original
Claude Design export — nothing in this folder is hand-edited. To rebuild it:

```sh
npm run media -- "/path/to/Darvis export"
```

The sources could not be pulled through the design sync tool, which truncates
any binary over 256 KB, so the export has to be on disk.

## What ships

Each clip exists twice. The browser takes the first line it can decode:

- **`.webm` — AV1.** The one almost everyone gets.
- **`.mp4` — H.264.** The fallback for Safari before 17.4 and older hardware.

Plus a `-poster.webp` still, shown before the clip has loaded. The agent clips
use their own portrait as the poster, so they have no separate poster file.

Agent portraits ship as `.webp` with a `.png` fallback, wired through
`<picture>`.

None of it carries an audio track; the sources had none either.

## The sphere

The sphere behind the AI headline shipped from Claude Design as
`ai-sphere.json`, a Lottie file — but it is not vector art. It is 300 PNG
frames at 160x160 encoded as base64 inside the JSON: 4.2 MB on disk, 3.1 MB
gzipped, more than every other clip on the page put together, for a decoration
smaller than a thumbnail.

It is now encoded as what it is, a ten-second loop: **84 KB** as AV1, 111 KB as
H.264. The frames carry transparency, but the section behind them is white, so
they are flattened onto white and need no alpha channel. The Lottie player is
gone with it — nothing is vendored any more.

The JSON stays in the design export as the source; `npm run media` regenerates
the video from it.
